## 5. 노트북 실행과 함정

프로젝트 루트 PowerShell:

```powershell
.\scripts\run_desktop_chat.ps1
.\scripts\run_desktop_chat.ps1 -Regression
.\scripts\run_desktop_chat.ps1 -Regression -Suite tools
```

- 대화는 한 줄씩 입력, `:reset` 새 대화, `:quit` 종료.
- 최신 빌드가 있으면 `-SkipBuild`. 소스 변경 후에는 빌드해야 한다.
- **실행 중 `:desktop:installDist`를 병렬 실행하지 않는다.** JAR 덮어쓰기로 실제 `ClassNotFoundException`이 발생했다. 모델 검증과 배포 빌드는 순차 실행한다.
- PC 중단/절전/세션 재개 후에는 프로세스와 로그를 확인한다. 예전 도구 세션 ID가 살아 있다고 가정하지 않는다.

- 수정 승인은 기본 거절. 저수준 CLI `--yes`는 테스트 DB 수정 허용이며 사용자 데이터에 무심코 쓰지 않는다.
- 문자·메일·일정은 **마지막 외부 화면 호출만 SIMULATED**다. 실제 발송/저장을 검증한 것이 아니다.
