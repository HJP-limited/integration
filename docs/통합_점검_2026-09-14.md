# 통합 상태 점검 — 2026-09-14

`통합_인수인계_2026-09-14.md`를 기준으로 `agent/Agent_0910`(`e6b9002`),
`upstream-ryeong/search_multiturn`(`734c63b`),
`upstream-ocr/r1_phase2_sprint_c`(`010d3b1`)과 현재 통합본을 다시 대조한 결과다.

## 결론

- Agent/도구 공유 모듈의 동일 경로 Kotlin·Java 제품 파일 누락은 없다. 통합본은 원본에
  `ConversationalFollowup`, 붙여쓴 검색 보정, 단일 색인 문자열 규칙과 관련 시험을 더한 상태다.
- OCR 제품 경로의 누락은 없다. `ref_pipeline.py`는 비교용 Python 구현이라 이식 대상이 아니고,
  `doc_ori`는 EXIF 우선 정책에 따라 의도적으로 제외했다. KIE 분류기와 토크나이저는 Android
  런타임에서 10개 canary를 모두 통과했다.
- 앱 계층은 원본 `AgentViewModel`을 그대로 복사하지 않고 Application 수명의 `ChatSession`,
  Room 저장소, OCR/UI를 결합한 구조다. 원본 앱 시험 상당수는 오래된 `com.example.hjp.eval`
  의존성 때문에 원본 자체에서 컴파일되지 않아 의도적으로 가져오지 않았다. 제품 코드 누락과는
  별개지만 검증 공백이므로 아래의 현재 구조용 계측 테스트를 추가했다.

## 새로 발견해 고친 실제 누락·오류

1. **사전계산 임베딩 로더 누락**
   - `cards_embeddings.bin`, ID, 지문 파일은 APK에 있었지만 읽는 코드가 0곳이었다.
   - ryeong 원본의 `seedEmbeddingsFromAsset()`가 통합 중 빠진 것이다.
   - 카드 지문과 ID/벡터 SHA-256을 검증해 1000개 문서 벡터를 Room에 적재하도록 복원했다.
   - 라이브 문서 임베딩과 Python 사전계산이 `EmbeddingInput`의 동일한 문자열을 쓰게 했다.
   - 번들이 손상되면 검색 전체를 죽이지 않고 경고 후 라이브 계산 경로로 내려간다.
2. **신규 기기 설치 스크립트 null 오류**
   - 기기에 모델이 아직 없으면 `adb stat` 출력이 없어 `$null.Trim()`에서 중단됐다.
   - 문자열 캐스팅 후 비교하도록 고쳤다.
3. **검증·문서 불일치**
   - KIE 크기, APK 크기, 모델 개수, 축소/원본 토크나이저 설명을 현재 자산과 맞췄다.
   - 과거 `MODEL_SETUP_STATUS.md`에는 현재 문서가 아님을 표시했다.
4. **OCR 네이티브 세션 해제 누락**
   - 촬영 화면을 나간 뒤에도 det/rec/방향/KIE ONNX 세션이 닫히지 않았다.
   - 각 계층을 `AutoCloseable`로 만들고 Compose 화면 이탈·취소와 KIE canary 실패 시 모두
     해제하도록 고쳤다. 대형 Gemma와 연속 실행할 때의 불필요한 메모리 압박을 제거했다.

## 남은 단계

물리 arm64 기기가 연결되면 `REAL_DEVICE_TEST.md`의 설치 스크립트를 실행한다. 스크립트가 모델
3개의 로컬/기기 SHA-256을 확인하고 아래 네 테스트를 자동 실행한다.

- `RequiredModelsInstrumentedTest`: 모든 생성·임베딩·OCR/KIE 모델 로드(누락 시 즉시 실패)
- `OcrAssetsInstrumentedTest`: KIE 실제 분류 10/10
- `LiteRtGatewayToolCallInstrumentedTest`: 실제 Gemma 생성 + 날짜·시각 도구 호출
- `EmbeddingGemmaArm64InstrumentedTest`: 번들 문서 벡터 + 라이브 쿼리 벡터 하이브리드 검색
- 메일/일정 작성 화면을 열었다 돌아와도 진행 중 턴과 대화가 유지되는지 수동 확인
- 가능하면 기존 v4 사용자 DB 백업본으로 4→5 최종 스모크 테스트

외부 `integration_evidence`의 출처는 현재 세 원본 리모트 어디에도 확인되지 않았다. 이 폴더를
받기 전까지 관련 13개 게이트는 환경 의존 실패로 남는다.
