## 이번 수정

1. **원본 Agent 후속 변경 반영**: 명시적인 새 대상의 검색 필요 여부·검색어를 라우트 계약과
   모델 문맥에 전달하고, 직책 검색 어휘와 진단 필드를 보완했다.
2. **통합 회귀 수정**: 원본의 단어 포함 판정이 `이메일 알려줘` 및 동작 단어가 포함된 이름의
   속성 조회를 발송 전 대상 확보로 오인했다. 기존 이름 인식 기반 의도 분류를 공유하도록 고쳤다.
3. **실제 gateway 순서 보존**: 원본의 커널 선행 검색을 그대로 이식하면 사용자 턴 입력 없이
   도구 결과부터 native gateway에 전달할 수 있다. 통합본은 사용자 입력을 먼저 전달하고 검색
   의무를 문맥과 워크플로에 반영한다. 이 조정의 실제 Gemma 동작은 실기기 검증이 필요하다.
4. **이전 검색 후보 동기화**: 새 사람을 명시하면 typed memory의 후보와 capability state의
   `contact.last_search_results`를 함께 제거한다. 언급 기록과 관계없는 도구 상태는 보존한다.
5. **임베딩 저장 재시도**: Room 임베딩 저장이 성공하기 전에 검색 서비스를 캐시에 공개하던
   순서를 수정했다. 첫 저장 실패 후 다음 요청이 저장을 재시도하고 정상 복구하는 시험을 추가했다.
6. **OCR 실패 시 자원 해제**: 초기화 도중 실패하면 이미 연 ONNX 세션을 역순으로 닫고,
   SessionOptions도 해제한다. Bitmap 변환 예외도 Mat 해제 범위에 포함했다.
7. **설치 문서 정정**: 의미검색에 키워드 폴백이 있다는 오래된 설명을 제거했다. LLM 모델은
   자동 다운로드가 아니라 파일 가져오기 또는 설치 스크립트로 배치하며 가져온 뒤 프로세스를
   재시작한다.
